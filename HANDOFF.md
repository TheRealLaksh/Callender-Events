## Project in one paragraph

tracking), installs as a PWA and works offline. It began as a Unified Mentor internship prototype (Jun to Aug 2025, a CDN
Tailwind page) and was rebuilt on 9 Oct 2026 as a typed, tested app (PR #1 and #2). Personal project, no client.

## Stack and how to run

- Vite 7, strict TypeScript, no UI framework, `vite-plugin-pwa`. Vitest (71 unit tests) and Playwright (43 e2e tests, axe a11y audits).
- `npm install`, then `npm run dev`, `npm run build`, `npm run test:all` (typecheck + unit + e2e; first e2e run needs `npx playwright install chromium`).
- Deploy: push to `main`, Vercel builds `npm run build` and publishes `dist/` (`vercel.json` holds the security headers and caching; keep it in sync with `netlify.toml`, which is now unused). The strict CSP is injected into the page by `vite.config.ts`.
- The README has the full feature list, data format (`calibridge:v2` in localStorage) and known limitations.

## Code map

- `src/core/`: pure logic with unit tests (time zones, recurrence, .ics, quick-add parsing, reminders, week layout).
- `src/state/`: event store (undo/redo, persistence) and prefs. `src/services/`: notifications, reminders, file helpers.
- `src/ui/`: DOM components; `views/` holds month, week, agenda. `tests/` unit, `e2e/` browser tests.
- `public/`: `favicon.svg` (logo source), `icon-192.png`, `icon-512.png` (also the og:image), `icon-maskable-512.png`, `apple-touch-icon.png`.

## Logo

Redrawn 9 Oct 2026 (Laksh disliked the old calendar-page-with-wave mark). New mark: an arch of seven day dots (today, the top
one, in green `#34d399`) over a white bridge deck, on an indigo gradient tile (`#7c83ff` to `#4f46e5`, `rx` 16). `favicon.svg` is
hand-written; the PNGs were rendered from the same shapes with Playwright (maskable and touch icons are full-bleed with the mark
scaled to 78% and 94%). To change the logo, edit `favicon.svg`, then re-render all four PNGs so they stay in sync.
